# Voces Indígenas — condiciones de acceso al contenido
#
# Este archivo replica lo que impactoindigena.news ya declaraba. Al mudar el
# contenido a vocesindigenas.org la declaración se quedó en el dominio viejo, que
# hoy solo redirige: durante ese tiempo el sitio donde vive todo el contenido no
# expresó ninguna reserva. Verificado el 6-sep-2026: nueve bots bloqueados allá,
# cero acá.
#
# LO QUE SE PERMITE Y LO QUE NO, y por qué:
#
#   SÍ · buscar, indexar y CITAR con enlace. Los bots de búsqueda y de respuesta
#        con atribución —Googlebot, OAI-SearchBot, ChatGPT-User, PerplexityBot,
#        Claude-SearchBot y los demás— NO están en la lista de abajo, a propósito.
#        Traen lectores y citan la fuente. Cerrarles la puerta seria desaparecer
#        de donde cada vez más gente busca noticias.
#
#   NO · entrenar modelos. Los de abajo descargan el contenido para entrenar y no
#        devuelven ni un lector ni una atribución. Bloquearlos no cuesta
#        visibilidad: cuesta cero.
#
# Dos de la lista no son rastreadores: `Google-Extended` y `Applebot-Extended`
# son señales para excluirse del entrenamiento de Gemini y de Apple, y **no
# afectan a Googlebot ni a la búsqueda de Google**.
#
# Y el fundamento, que no es solo comercial: este proyecto respeta el robots.txt
# de los medios que rastrea —medido en agosto, 0 de 80 nos bloquean y aun así se
# respeta— y sostiene que el conocimiento indígena no se extrae sin
# consentimiento de quien lo tiene. Pedir para el contenido propio lo mismo que
# se concede al ajeno es consistente.
#
# Content-Signal es una convención, no un candado: declara una voluntad y no
# impide técnicamente nada. Las restricciones expresadas aquí son reserva expresa
# de derechos conforme al artículo 4 de la Directiva (UE) 2019/790.
